# Airbnb Data Analysis

Airbnb Data Analysis is a **data analytics project using Python** that explores patterns in Airbnb listings such as pricing, neighborhood distribution, availability, and room types. The project uses exploratory data analysis (EDA) and visualizations to understand trends in the Airbnb marketplace.

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
- NumPy
- Google Colab / Jupyter Notebook

## Key Features
- Analyze **average price by neighbourhood group**
- Compare **room type distribution**
- Identify **top neighbourhoods with most listings**
- Explore **availability patterns of listings**
- Generate **visual insights using charts and graphs**

## Dataset
The dataset contains Airbnb listing information including:

- Listing ID and host details
- Neighbourhood group and location
- Room type
- Price
- Availability throughout the year
- Number of reviews

## What This Project Demonstrates
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization techniques
- Extracting insights from real-world datasets

## Key Insights
- Average pricing differences across neighbourhood groups
- Most common room types listed on Airbnb
- Areas with the highest concentration of listings
- Availability trends of Airbnb properties

This project demonstrates how **data analytics can be used to understand pricing trends and listing behavior in the short-term rental market.**
